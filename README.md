# Seminar-on-CNN-application-on-ai-healthcare
Seminar presentation on “Predicting Glaucoma Before Onset Using Convolutional Neural Networks (CNNs).” This seminar explores how Machine Learning, particularly CNNs, can be used to analyze retinal images and identify patterns associated with glaucoma at an early stage. The presentation is supported by references from medical research, medical textbooks, and resources from the Glaucoma Research Foundation.
